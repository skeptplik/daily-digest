> ВНИМАНИЕ: это первоначальная инструкция по установке. Актуальные расписание (задача Claude в 06:12 по Варшаве), схема с RSS-сбором заголовков, ограничения (без WebSearch/WebFetch) и состояние описаны в `docs/` (начните с `docs/STATUS.md` и `docs/OPERATIONS.md`). Актуальный промпт задачи: `routine_prompt.md`. Папка `local` после установки задачи Windows не нужна (скрипт копируется в `C:\Digests`).

# Инструкция по настройке ежедневного дайджеста

Порядок: A (секреты) → Б (загрузка файлов) → В (проверка доставки) → Г (подключение GitHub к Claude) → Д (задача на 8:00) → Е (папка на компьютере).
Токены и пароли никому не присылайте, они должны быть только в GitHub Secrets.

## Если репозиторий уже создан раньше

Шаги «репозиторий + Pages» пропустите. Достаточно заменить файлы (шаг Б) и вставить новый промпт в задачу (шаг Д, пункт 3).

## Подготовка (один раз)

1. На github.com нажмите **+ → New repository**, имя `daily-digest`, **Public**, галочка **Add a README file**, **Create repository**.
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. В Telegram: откройте своего бота и нажмите **Start**. Свой числовой ID узнайте у бота @userinfobot. Токен бота лежит в @BotFather (`/mybots` → бот → **API Token**).

## A. Секреты для Telegram

1. Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**.
2. Name: `TELEGRAM_BOT_TOKEN`, Secret: токен бота → **Add secret**.
3. Снова **New repository secret**: Name `TELEGRAM_CHAT_ID`, Secret: ваш числовой ID → **Add secret**.

Делайте это до загрузки файлов, тогда пробное сообщение придёт сразу.

## Б. Загрузка файлов

1. Распакуйте zip (правой кнопкой → **Извлечь всё**).
2. В репозитории: **Add file → Upload files**.
3. Перетащите в окно браузера СОДЕРЖИМОЕ распакованной папки (папки `.github`, `data`, `local`, `scripts`, `templates` и файлы). Если `.github` не видна, в Проводнике включите «Вид → Показать → Скрытые элементы».
4. Внизу нажмите **Commit changes**.

Если `.github` не перетаскивается: **Add file → Create new file**, в имени введите `.github/workflows/publish.yml`, вставьте текст из одноимённого файла, **Commit changes**.

## В. Проверка доставки

1. Вкладка **Actions**. Должен запуститься **Publish digest** (build, deploy, notify, все зелёные).
2. Если запуска нет: **Actions → Publish digest → Run workflow**.
3. В Telegram придёт сообщение «ДЕМО», ссылка и файл. Откройте ссылку на телефоне.
4. Красный шаг? Откройте его и пришлите текст ошибки (токены GitHub скрывает сам).

## Г. Подключение GitHub к Claude

1. Откройте claude.ai/code и войдите.
2. Установите **Claude GitHub App**, на странице GitHub выберите **Only select repositories** и отметьте `daily-digest`.

## Д. Ежедневная задача (routine)

1. claude.ai/code/routines → **New routine**. В документации Anthropic эти задачи сейчас называются «scheduled tasks» (раньше routines), это то же самое.
2. Название: `Утренний дайджест`.
3. В поле промпта вставьте весь текст файла `routine_prompt.md`.
4. **Модель: Sonnet 5.5, уровень усилия (Effort): Medium.** В том же блоке, где поле промпта, есть выпадающий список модели. Выберите в нём Sonnet 5.5 явно, а не «Default»: по документации Claude Code на тарифе Pro значение по умолчанию это Opus 5.5, он тут не нужен. Fable на Pro тоже не берите, он расходует платные кредиты.
5. Репозиторий: `daily-digest`.
6. **Permissions → Allow unrestricted branch pushes** (включить). Без этого Claude пишет только в ветки `claude/...`, а публикация слушает `main`.
7. Триггер **Schedule**: каждый день 8:00, проверьте свой часовой пояс.
8. Создайте задачу и запустите вручную (**Run now**). Через 5–10 минут в Telegram придёт настоящий дайджест без пометки «ДЕМО». Не нажимайте Run now много раз подряд: пробные запуски тоже расходуют лимит подписки.

Если Claude не может открыть сайт, проверьте в настройках среды задачи раздел сетевого доступа.

## Е. Папка на компьютере

Убрано 4 ноября 2026: дайджест читается только на телефоне.

## Настройка источников

Файл `data/sources.json` в репозитории: списки изданий, которым доверяет дайджест. Откройте его на GitHub (значок карандаша) и добавляйте или удаляйте домены. Правила в промпте:
- берутся только издания из списка и первоисточники;
- для политики нужно подтверждение двумя независимыми изданиями, иначе в истории появится пометка «⚠️ Пока сообщает один независимый источник»;
- никакой список не гарантирует полной нейтральности, поэтому по политике полезно иногда проверять ссылки в историях.

## Языки (RU / EN / DE)

- Дайджест только на русском: заголовки и пересказы Claude пишет по-русски, даже если источник английский. Где у издания есть русская версия статьи, он ссылается на неё.
- Переводы на другие языки отключены ради экономии лимита. Переключатель RU / EN / DE на странице умеет работать, но показывается только если в данных есть переводы, поэтому сейчас его не видно.
- Страницы статей по кнопке «Читать» открываются на языке издания. В Chrome на телефоне их можно перевести на русский через меню ⋮ → «Перевести».

## Расход лимита и модель

- Рекомендация: Sonnet 5.5 на уровне Medium. Причины в чате; коротко: задача многошаговая (поиск, сверка источников, нейтральный пересказ, строгий JSON, git), и здесь важна надёжность, а не скорость.
- После первых запусков загляните в claude.ai → Settings → Usage и посмотрите, сколько лимита ушло.
- Если расход велик, сначала уменьшите число поисков в `routine_prompt.md` (сейчас до 30). Если и этого мало, можно попробовать Haiku 5.5 на неделю и сравнить качество (особенно политику и корректность JSON) с Sonnet.
- Если Claude стал пропускать проверку источников или ошибаться в файле, поднимите Effort до High.
