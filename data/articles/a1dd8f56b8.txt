Microsoft has reminded customers again that Windows Server 2016 will stop receiving security updates after it reaches the end of support in two months.
This follows another warning issued in October, announcing the end of extended support for Windows Server 2016 and encouraging users to upgrade to Windows Server 2025.
Windows Server 2016 reached general availability on October 12, 2016, one month after its official release at Microsoft's annual Ignite conference in September of that year.
It also reached the end of mainstream support nearly 4 years ago, in January 2022, and extended support will end in roughly two months, on January 13, 2027.
On the same date, the company will also stop support for all Windows Server 2016 Essentials features, including Remote Web Access and related Essentials-specific functionality.
"On January 13, 2027, all editions of Windows Server 2016 will reach the end of extended support. The January 2027 Windows security update will be the last update provided during extended support," Microsoft said in a message center update.
"After that date, monthly security updates will continue only for Windows Server 2016 devices enrolled in Extended Security Updates (ESU)."
Windows Server 2025 upgrade
Before Windows Server 2016 stops receiving security updates, Microsoft advised IT administrators to switch to Windows Server 2025, which started rolling out to Windows Insiders in January 2024 and reached general availability in November 2024.
Admins who want to test Windows Server 2025 before deploying it across their organization can get a free 180-day trial via the Microsoft Evaluation Center.
Windows Server 2025 is the latest Long-Term Servicing Channel (LTSC) release for Windows Server, and it will reach the end of mainstream support in November 2029, with an additional five years of extended support until November 14, 2034.
More information about Windows servicing dates is available on the Windows Lifecycle FAQ page or via the Lifecycle Policy search tool.
Last month, Microsoft announced that devices running Windows 11 24H2 Home and Pro editions stopped receiving security and non-security preview updates and advised customers to upgrade to Windows 11 26H2 by installing the Windows 11 2026 Update.
On Friday, it also reminded customers that they can enroll in the Extended Security Updates (ESU) program after Windows 10 Enterprise LTSC 2021 (a stripped-down Windows 10 edition for mission-critical devices) reaches the end of mainstream support in January, until they can upgrade to Windows 11 Enterprise LTSC 2024.
