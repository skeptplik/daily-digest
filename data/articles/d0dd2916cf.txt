Microsoft confirmed that some Forcepoint users may experience printing issues after installing the November 2026 Windows 11 hotpatch.
In a Friday service alert seen by BleepingComputer, Microsoft said this known issue affects only systems running Windows 11 24H2 and later.
According to Microsoft, the printing problems stem from a compatibility issue between the KB5132043 Windows hotpatch update and the Forcepoint DLP Endpoint Agent endpoint data loss prevention solution.
"After installing the November 2026 Windows hotpatch update (the Originating KBs listed above), devices running Forcepoint DLP Endpoint Agent might experience printing issues," Microsoft said. "Affected users might find that the print option is greyed out or encounter errors when selecting a printer. This issue occurs because the Print Spooler service fails to start."
While a fix is not yet available, Forcepoint has customers signing in to the Forcepoint support portal.
Last week, Microsoft also warned that the KB5132043 hotpatch is causing installation and launch issues affecting Office and third-party applications on Windows 11 systems.
These two known issues should not affect systems with the standard November 2026 Patch Tuesday security updates, only those that have installed the hotpatch updates pushed through Microsoft's Windows Autopatch, a cloud-based enterprise service designed to automate Windows and Microsoft 365 updates.
However, as the company confirmed two weeks ago, the November 2026 Patch Tuesday security updates may also break printing for users trying to print documents with complex formatting on server (Windows Server 2016 or later) and client (Windows 10 or later) devices.
Microsoft unveiled Windows Autopatch in April 2022, saying it would be available for free to customers with a Windows 10/11 Enterprise E3 license or greater starting in July 2022. Windows Autopatch was made available in public preview in early June 2022 and reached general availability in July 2022.
In March, it announced that it would turn on hotpatch security updates by default for all eligible Windows devices managed through Microsoft Intune and the Graph API on systems with the May 2026 Windows security updates installed.
One month later, Microsoft fixed a Windows Autopatch bug that deployed driver updates restricted by administrative policies on some Autopatch-managed Windows devices belonging to customers across the European Union.
