Microsoft has released emergency out-of-band updates to fix Windows activation and licensing failures caused by this month's security updates.
As the company confirmed in a Wednesday service alert, this known issue affects organizations that use the Software Licensing Management Tool (SLMGR) command-line tool to automate Windows activation and licensing processes.
However, Microsoft said that enterprise customers who don't use SLMGR for licensing management and have the KMS client key installed in their image are unaffected.
"Devices that are already activated remain activated. Customers whose devices already have the appropriate KMS client key and KMS configuration, and who do not need to run the affected Slmgr.vbs commands, are not expected to be affected," the company noted.
On Friday, Microsoft released multiple emergency Windows updates to fix the bug on the following client (Windows 10 21H2/22H2 and Windows 11 23H2) and server (Windows Server 2019/2022/2025) platforms:
- Windows Server 2025: KB5136489
- Windows Server 2022: KB5136487
- Windows Server 2019 and Windows 10 Enterprise LTSC 2019: KB5136490
- Windows 11, version 23H2: KB5136483
- Windows 10, version 22H2 ESU and Windows 10 Enterprise LTSC 2021: KB5136493
For Windows Server 2025, Windows Server 2022, Windows Server 2019, and Windows 10, the out-of-band updates are available only through the Microsoft Update Catalog.
The Windows 11, version 23H2 optional OOB update is available through Windows Update and the Microsoft Update Catalog and can be installed from Settings > Windows Update > Advanced options > Optional updates to download.
"This cumulative update includes the improvements from the November 2026 Windows security update," Microsoft added. "For complete guidance and installation instructions, see the relevant KB articles."
In January, Microsoft resolved a similar issue that was causing Windows license migration failures during upgrades because impacted devices couldn't register with the Windows Activation server for digital licenses.
Last week, it also acknowledged that Windows updates released since the October Patch Tuesday are triggering SQL Server performance and stability issues and that the November 2026 Windows 11 security updates fail to install on systems with the October 2026 preview update.
