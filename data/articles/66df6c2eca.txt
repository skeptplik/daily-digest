In August, Facepunch removed the controversial Battle Pass system entry from this year's Rust roadmap. It was replaced with Rust Premium, a status that grants players who have at least $15 worth of items in their inventory access to premium servers, but not much else. This month's force wipe patch notes unveiled some additional details about the changes coming to Rust Premium "soon." As it turns out, Rust Premium will become a paid monthly servicewith exclusive perks and rewards.
Rust Premium is now available on the staging branch, the build that allows Rust players to test upcoming features before they go live. Within the Rust Premium menu, we can see which perks will be available to Premium users; among them is character customization — a feature that fans have been eagerly awaiting since the player model update.
Rust character customization expected to release in December
This feature was scheduled for 2026 Q4, meaning it's likely coming in the next force wipe. Rust fans can therefore expect Rust Premium and character customization to become available on Thursday, Dec. 3, when the monthly update drops.
Rust Premium subscribers will have access to special perks including Access Pass (what Premium is now, access to exclusive servers), queue priority for maximum capacity servers, HD camera access on mobile, and character customization.
After digging through the staging branch files, user Protox believes that once players customize their character, they won't be able to change it for the rest of the wipe. So, they'd be stuck with it for a whole month. This makes sense as a way to prevent players from changing their appearances mid-wipe to unfairly deceive others in-game.
The first month of Premium features the Cobalt Premium pack, which includes launch reward skins for Sheet Metal Doors, Cobalt skins for the Metal Chest Plate and Code Lock, a Cobalt charm for weapons, and the Cobalt tattoo pack, a customization feature which will allow players to give their characters tattoos via a tattoo artist chair.
Similar to character customization, it's likely that players will be able to add tattoos onto their character throughout the wipe but will only be able to remove them the following month. While it's possible to play around with the upcoming tattoo feature, character customization can only be applied using code. Either it's not completely finished yet or deliberately inaccessible.
