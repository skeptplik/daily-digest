Microsoft warned customers earlier this week that the November 2026 security updates may break printing for documents with complex formatting.
As the company explained in a service alert seen by BleepingComputer, this known issue affects users attempting to print documents with images that have zero height or width on server (Windows Server 2016 or later) and client (Windows 10 or later) devices.
"After installing the November 2026 Windows security update (the Originating KBs listed above), or later updates, printing might fail for documents containing images rendered with a height or width value of zero at the selected printing resolution," Microsoft said.
"These images can be used as part of certain complex document formatting, such as adding "invisible" images intended to serve as a document watermark, layout anchoring, or generation tools that may inserting images objects even when no graphic present."
The bug mainly affects users printing Microsoft Word documents via the Windows Graphics Device Interface (GDI), but it may also trigger failures when printing from other applications.
Microsoft also addressed printing issues triggered by Windows updates in March and July 2025: the first caused USB printers to print random text, and the second broke the 'Print to PDF' feature.
More recently, the company notified customers that the August 2026 .NET Framework cumulative updates broke printing and PDF export in apps that use the Windows Presentation Foundation (WPF) UI framework.
This week, Microsoft also confirmed that this month's Patch Tuesday security updates trigger Windows activation and licensing failures with 0x80041008 error codes and that Windows updates released since the October Patch Tuesday cause SQL Server performance and stability issues.
Additionally, the company warned that the November 2026 Windows 11 security updates fail to install on systems with the October 2026 preview update.
