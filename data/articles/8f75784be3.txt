Website management platform Optimizely confirms hackers put malicious code into customer sites
A breach at a popular website management company exposed customers’ visitors to malicious code that stole cryptocurrency and attempted to skim payment cards or install malware.
Researchers at cybersecurity firm Report URI said they found malicious JavaScript code on 178 different widely visited websites run through the Optimizely Web experimentation platform. Optimizely allows companies to personalize and manage their websites and apps.
Optimizely confirmed the incident in a brief statement on Monday evening, writing that it “identified and contained a security incident affecting some Optimizely Web Experimentation customers.”
“The vulnerable path is blocked, the injected code was removed, and customers have been contacted directly,” the company said. It did not respond to requests for comment about the specifics of Report URI’s study.
In a technical advisory, Optimizely confirmed Report URI’s findings that a vulnerability in its Experimentation platform allowed threat actors to inject malicious JavaScript into some customers’ websites.
Report URI listed dozens of prominent companies impacted by the breach and used blockchain evidence to track at least $7,000 stolen through the malicious code.
“The malware was a multi-purpose kit. It swapped cryptocurrency wallet addresses for the attacker's, skimmed payment cards, stole cookies and screenshots, and on iPhones and iPads it delivered the Coruna and DarkSword iOS exploit kits. Crypto has already been stolen, with verified transactions to the attackers,” Report URI’s Scott Helme said.
Most of the malicious code has now been removed, but Helme urged companies that use Optimizely to check their websites. Helme said the infected Optimizely files have all been cleaned since they reported the incident.
Helme added that while they can track the stolen cryptocurrency, they have no way of seeing “how many credit cards were skimmed, how many cookies or screenshots were stolen, or how many iOS devices were infected before the attack was stopped.”
The malicious code was installed on 32 finance or banking websites and several platforms for technology, news, airline and retail companies.
Helme noted that they first saw the injected code on Turkish websites in September before the threat actor conducted its latest campaign on Monday.
Coruna and Darksword
Experts at cybersecurity firm Hudson Rock confirmed Report URI’s findings. Last week, threat hunting firm iVerify warned that cybercriminals are increasingly infecting devices on a large scale with spyware — with about 75% of detections involving criminal actors deploying Coruna or DarkSword exploit kits.
DarkSword allows users to be infected without clicking on a link. Simply visiting a compromised website through a web browser can trigger an attack. Coruna is also delivered via web-based attacks, where people visiting malicious sites trigger WebKit and kernel vulnerabilities.
Research from InfoStealers also found that poisoned third-party JavaScript has been actively routing iOS visitors into Coruna and DarkSword exploit-kit infrastructure.
Collin Hogue-Spears, a cybersecurity expert at Black Duck, said companies typically use the affected Optimizely tool so that teams can change a live website without a code release. The attacker's loader went into Project JavaScript, the field where a customer adds custom code to Optimizely.
“The Optimizely skimmer reads forms the affected sites built themselves; a payment processor's hosted iframe sits outside its reach, so security teams at affected companies must reconstruct which pages loaded the infected Optimizely snippet, for how long, and which card payments those pages took in that time period,” he said.
“If the Optimizely skimmer ran unblocked on a page with your own card form, count as exposed every card entered there while the skimmer was live.”
The incident resembles a recent incident impacting movie ticket site Fandango, which notified state regulators that payment card numbers, CVV numbers, expiration dates and more were stolen when hackers put malicious code into the sites' ticketing checkout page.
