Broadcom on Tuesday announced the release of patches for 23 vulnerabilities across multiple VMware products, including critical-severity flaws in ESX and vCenter.
The vCenter patches resolve seven bugs, including a critical authentication bypass issue in the VMware Directory Service tracked as CVE-2026-123903 (CVSS score of 9.8).
Additionally, the fixes target three denial-of-service (DoS) issues in the VMware Directory Service, a local privilege escalation in a vpxd service script, an arbitrary file write while processing certain archives, and a security policy enforcement failure in the vSphere Distributed Switch (vDS).
The ESX updates resolve seven security issues as well, including three critical-severity weaknesses leading to code execution on the host.
CVE-2026-123910 and CVE-2026-123911 (CVSS score of 9.8) are heap out-of-bounds write and use-after-free flaws in the I/O filter service, while CVE-2026-123912 (CVSS score of 9.3) is an out-of-bounds write vulnerability in the XHCI USB controller that requires local administrative privileges on a virtual machine.
An attacker “may exploit this issue to execute code as the virtual machine’s VMX process running on the host. On ESX, the exploitation is contained within the VMX sandbox whereas, on Workstation and Fusion, this may lead to code execution on the machine where Workstation or Fusion is installed,” Broadcom explains.
The remaining four include a stack-based buffer overflow in the VMkernel, a DoS vulnerability in guest RPC, a security bypass in the host configuration store, and a signature verification bypass.
Broadcom also patched eight flaws in Avi Load Balancer that could lead to code execution with root privileges, privilege escalation to root, command execution, password hash leaks, access to the routing management interface and other resources, and unintended file access, and one in VMware Tools leading to DoS.
According to Broadcom, some of the issues were resolved with the vCenter updates released last week. vCenter version 8.0 U3m contained the fixes, and customers who applied it do not need to update again. vCenter 9.1.x deployments, however, as well as ESX, VMware Tools, Workstation, Fusion, and Avi Load Balancer instances, need to be updated.
“Patches are cumulative, so the updates listed in this advisory also contain the fixes from VMSA-2026-0009 when they are newer than the fixed versions listed in VMSA-2026-0009. However, this advisory does not mention the SDDC Manager updates from VMSA-2026-0009; please ensure you are handling those,” the company notes.
Broadcom makes no mention of any of these vulnerabilities being exploited in the wild, but it’s not uncommon for the company to not warn about exploitation in its public advisories.
On Tuesday, Broadcom also updated its advisory on Node2Shell to add VMware Cloud Foundation version 9.1.2 to the list of fixed releases.
