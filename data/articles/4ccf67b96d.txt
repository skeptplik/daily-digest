Microsoft has announced Windows Server 2028, the next major release of its server operating system, at the Ignite 2026 conference on Tuesday.
This new Windows Server version ships with a hardened Server Core configuration by default and a new security baseline that allows admins to relax specific settings.
"A hardened Server Core configuration by default and a new security baseline help reduce the work of establishing a secure baseline from day 1," said Neil Hinnant, Director of Windows Server & I/O Fabrics PM.
"Trusted Launch extends protection to virtual machines, guaranteeing boot integrity across your VM fleet, and Confidential VM support begins a journey to support integrity-protected runtimes on supported CVM hardware."
The list of hardened Server Core settings is extensive and includes:
- Identity and authentication: Credentials are hard to steal and hard to reuse: Kerberos over NTLM, LSASS protected, strong passwords and account lockout, no consumer accounts.
- Network exposure: The server talks only over signed, encrypted, authenticated channels: SMB signing and encryption, the firewall on in every profile, legacy name resolution and unauthenticated RPC off.
- Cryptography: TLS is limited to modern cipher suites, key exchange is hybrid post-quantum (ML-KEM), and stored keys are strongly protected.
- Privilege and admin access: Admins approve elevation, powerful rights stay with Administrators, Guests cannot sign in, and installers cannot elevate on their own.
- Platform and code integrity: The sign-in process runs only Microsoft-signed code. Signature validation is stricter. The paging file is encrypted.
- Remote access and observability: RDP with NLA and TLS, WinRM without Basic, Digest, or unencrypted traffic, advanced audit with command lines, PowerShell script block logging, and larger event logs.
However, the company said it's still working on adding NTLM blocking, hardware-backed platform protection, print and RPC hardening, and more to the hundreds of security settings enabled from first boot.
Windows Server 2028 also offers simplified administration and management at scale through Intune management for Windows Servers, bringing endpoint-management workflows for configuration, compliance, applications, and updates to eligible, persistent servers.
It also improves performance with native NVMe storage enabled by default, NVMe over TCP and RDMA transports, and the ability to boot from ReFS.
Last but not least, it introduces new AI accelerators, including the ability to deploy and configure inference environments, manage accelerated hardware, and support open-weight and custom models (including Windows ML, Foundry Local, vLLM, and Llama.cpp).
Admins who want to test Windows Server 2028 can register for the Windows Insider Program for Windows Server or apply to enroll in the Windows Server Technology Adoption Program (TAP) for earlier access.
"This major release raises the security and access bar, accelerates enterprise infrastructure, and simplifies management at scale," Hinnant added. "It also begins our long term investments extending Microsoft Foundry to bring AI inference to fleets of local token factories, giving customers more choices to put the right intelligence in the right place with the right cost structure."
