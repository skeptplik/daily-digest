The Drupal security team has confirmed that a critical vulnerability that lets attackers hijack unpatched sites has been actively exploited since at least Thursday.
Drupal is a content management system (CMS) commonly used by large organizations, including government entities, major research universities, and high-profile enterprise and media organizations.
The security flaw, tracked as CVE-2026-132165, was discovered by Anthropic's OSS Scanner and can be exploited by anonymous users to gain remote code execution or take over vulnerable sites by abusing the Drupal installer.
"Drupal core ships with an install.php file for installing Drupal core. Under specific conditions, an attacker can use the installer to attempt to reinstall Drupal. This can lead to a site takeover or remote code execution," the Drupal security team warned last Wednesday. "Some exploit paths are mitigated if the web server cannot write to or change permissions on settings.php."
While it wasn't initially flagged as abused in the wild, in an update to the original security advisory, Drupal warned that this flaw has been "exploited on live sites as early as 2026-11-19 19:00 UTC."
Websites using the paid Drupal Steward Web Application Firewall (WAF) service are already protected from known attack vectors, but admins are still advised to upgrade to the latest available Drupal version in case other attack vectors are discovered.
Those who can't immediately upgrade should block access to /core/install.php in the web server configuration or the .htaccess file in the web root to secure the Drupal installer.
On Tuesday, the US Cybersecurity and Infrastructure Security Agency (CISA) has also added the vulnerability to its Known Exploited Vulnerabilities (KEV) Catalog and ordered federal agencies to secure their systems against ongoing attacks by Friday, November 27.
"These types of vulnerabilities are a frequent attack vector for malicious cyber actors and pose significant risks to the federal enterprise," the agency warned. "While BOD 26-04 applies only to FCEB agencies, CISA encourages all organizations to adopt risk-based vulnerability management and prioritize remediation of KEV Catalog vulnerabilities."
Since November 2021, CISA has tagged five Drupal vulnerabilities as abused in the wild, two of which have also been exploited by ransomware groups.
