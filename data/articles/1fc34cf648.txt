Microsoft has shared a workaround for installation and launch issues affecting Office and third-party applications after installing this month's Windows 11 hotpatch.
In a service alert seen by BleepingComputer, Microsoft told IT administrators that these problems may appear during installation, launch, or even during normal app use on systems running Windows 11 24H2 and later.
"Devices which installed the November 2026 hotpatch update (the Originating KBs listed above), might experience an error when installing, launching, or running some applications. Resulting from this issue, errors similar to "ERROR_ALLOTTED_SPACE_EXCEEDED (0xC0000099)" are displayed," Microsoft said.
"Current investigation suggests this issue occurs for applications which load the 32-bit Windows Installer DLL, found as msi.dll. This can happen more frequently with 32-bit applications, but can also occur for 64-bit applications under certain conditions."
Microsoft added that this known issue should not impact systems that have installed the standard November 2026 Patch Tuesday security updates, but only those that have installed the hotpatch updates pushed through the Windows Autopatch, the company's cloud-based enterprise service that automates Windows and Microsoft 365 software and security updates.
Until a fix is available, Microsoft has shared a workaround to help IT admins temporarily mitigate the bug on affected systems.
To do that, they have to edit the Windows Registry to increase the HotPatchTableSize using the following procedure:
- Open the Windows Registry by opening the Start menu, typing "regedit", and selecting Registry Editor from the results.
- Using the folders and address path, navigate to the HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management folder.
- In the right-hand panel, locate the "HotPatchTableSize" registry key, open it, and set the Value to "2000". Click OK.
- Close the registry editor and restart the device.
"Before you modify the registry, back it up and make sure that you know how to restore it if a problem occurs. For more information, see How to back up and restore the registry in Windows," Microsoft said.
Microsoft said in March that it would turn on hotpatch security updates by default for all eligible Windows devices managed through the Microsoft Graph API and Microsoft Intune, after the May 2026 Windows security updates are installed.
One month later, it fixed a Windows Autopatch bug that caused driver updates restricted by administrative policies to deploy on some Autopatch-managed Windows devices belonging to customers in the European Union.
Microsoft first announced Windows Autopatch in April 2002, saying it would be available for free to customers with a Windows 10/11 Enterprise E3 license or greater starting in July 2022. The feature reached public preview in early June and has been generally available since July 2022.
