This week's Java roundup for November 16th, 2026, features news highlighting: the Java4Shell RCE vulnerability; Oracle CSPUs; Lazy Constants targeted for JDK 28; the November 2026 edition of Azul Payara; point releases of Java Operator SDK, LangChain4j and Micrometer; maintenance releases of Liberica JDK and Helidon; and second release candidates of Hibernate Reactive.
OpenJDK
Oracle has released versions 27.0.1.0.3, 25.0.5.0.3, 21.0.13.0.3, 17.0.21.0.3, 11.0.33.0.3 and 8u511b3 of the JDK as part of their quarterly Critical Security Patch Update Advisory for November 2026. Further details on this release may be found in the release notes for version 27.0.1.0.3, version 25.0.5.0.3, version 21.0.13.0.3, version 17.0.21.0.3, version 11.0.33.0.3 and version 8u511 b33.
JEP 547, Lazy Constants (Fourth Preview), has been elevated from Proposed to Target to Targeted for JDK 28. This JEP proposes a fourth preview, with no changes, after three rounds of preview delivered in the upcoming release of JDK 27 and JDK 26 through JDK 25. Formerly known as Stable Values and Computed Constants, this feature introduces the concept of computed constants, defined as immutable value holders that are initialized at most once. This offers the performance and safety benefits of final fields, while offering greater flexibility as to the timing of initialization. The name change from Stable Values to Lazy Constants with the release of JDK 26, better captures the intent of a high-level use case.
JEP 548, Vector API (Thirteenth Incubator), has been elevated from its JEP Draft 8397768 to Candidate status. This JEP proposes a thirteenth incubation with one notable change, after twelve rounds of incubation delivered in JDK 16 through JDK 27. This feature introduces an API to "express vector computations that reliably compile at runtime to optimal vector instructions on supported CPU architectures, thus achieving performance superior to equivalent scalar computations." This JEP adds support for Vector<Float16> vectors, whose lanes hold 16-bit floating-point numbers in the IEEE 754 binary16 format. The Vector API will continue to incubate until the necessary features of Project Valhalla become available as preview features. At that time, the Vector API team will adapt the Vector API and its implementation to use them, and will promote the Vector API from Incubation to Preview.

Java4Shell
A new Remote Code Execution (RCE) vulnerability, known as Java4Shell (CVE-2026-114938), affects versions 27.0.1.0.3, 25.0.5.0.3, 21.0.13.0.3, 17.0.21.0.3 and 8u511b33-perf of Oracle Java SE, versions 21.0.13.0.3 and 17.0.21.0.3 of Oracle GraalVM for JDK, and Oracle GraalVM Enterprise Edition: 21.3.20.0.3. As described in the CVE documentation:
[This] difficult to exploit vulnerability allows [an] unauthenticated attacker with network access via multiple protocols to compromise Oracle Java SE, Oracle GraalVM for JDK, Oracle GraalVM Enterprise Edition. Successful attacks of this vulnerability can result in takeover of Oracle Java SE, Oracle GraalVM for JDK, Oracle GraalVM Enterprise Edition. Note: This vulnerability can only be exploited by supplying data to APIs in the specified Component without using Untrusted Java Web Start applications or Untrusted Java applets, such as through a web service.
Organizations and projects that have addressed this CVE include: BellSoft, Azul, JetBrains, GraalVM, Quarkus and WildFly. InfoQ will follow up with a more detailed news story.

Azul Payara
The release of Azul Payara 7.6.0, the November 2026 edition, includes Community Edition 7.2026.11, Enterprise Edition 6.44.0 and Enterprise Edition 5.93.0. Along with bug fixes and component upgrades, all three editions deliver resolutions to five CVEs, two of which are related to Azul Payara:
- CVE-2026-90908, a vulnerability in the GenericAdminAuthenticator class that allows a remote, unauthenticated attacker to bypass JMX/RMI administrative access restrictions by spoofing the client host address that may lead to remote code execution.
- CVE-2026-110003, A vulnerability in the administration REST interface that allows a remote, unauthenticated attacker to bypass secure-admin remote-access restrictions by supplying an arbitrary value in the X-GlassFish-authToken HTTP header that grants execution of arbitrary administrative commands, equivalent to complete compromise of the server.
Further details on this release may be found in the release notes and the Azul Payara security advisories page.
Hibernate
The second release candidates of Hibernate Reactive 5.1.0 and 5.0.0 ship with one single bug fix from the first release candidates, in which use of the Jakarta Persistence @TableGenerator annotation could cause a deadlock when a session holding the lock on the row of the generator table needed a new block of IDs.
Version 5.0.0.CR2 will be the last release candidate. With the GA release of version 5.0.0.Final, it will be declared as end-of-life and focus will be on version 5.1.0.
More details on these releases may be found in the release notes for version 5.1.0.CR2 and version 5.0.0.CR2.
Java Operator SDK
The release of Java Operator SDK 5.7.0 provides bug fixes, dependency upgrades and new features such as: the ability to enable virtual threads via construction in the Operator class or the josdk.use-virtual-threads property; and a new keepAlive() method, defined in the Operator class that starts a non-daemon thread to keep the JVM running until the operator is shut down. Version 5.7 is now built on Fabric8 Kubernetes Client 8.0. Further details on this release may be found in the release notes.
BellSoft
Concurrent with Oracle's Critical Security Patch Update (CSPU) for November 2026, BellSoft has released CSPU patches for versions 27.0.1.1 25.0.5.1, 21.0.13.1, 17.0.21.1, 11.0.33.1, 8u514 7u523 and 6u523 of Liberica JDK, their downstream distribution of OpenJDK, to address this list of CVEs. This release also includes a patch for the aforementioned Java4Shell Remote Code Execution vulnerability.
With an overall total of 111 fixes and backports, BellSoft states they have participated in eliminating 21 issues in all releases.
Helidon
The release of Helidon 27.0.2 delivers bug fixes and one notable change in which the default limit of decoded-input (strings, byte arrays, JSON, forms, and buffered multipart parts) for in-memory entity conversations has been increased to 1 mebibyte (MiB). More details on this release may be found in the release notes.
This release also aligns with the Oracle Critical Patch Updates for November 2026 and includes the Helidon 4.x and 3.x release trains as described in this blog post.
LangChain4j
The formal release (along with the thirty-fourth beta release) of LangChain4j 1.24.0 ships with bug fixes, documentation improvements, dependency upgrades and new features such as: new DecisionSchedulerPlanner and DecisionModels classes to serve as a decision model-based agentic pattern; and support for resuming suspended agentic systems in the AgentMonitor class. Further details on this release, including breaking changes, may be found in the release notes.
Micrometer
After two milestones and two releases candidates, the GA release of Micrometer Metrics 1.18.0 provides bug fixes, documentation improvements, dependency upgrades and new features such as: an optimization of the PrometheusMeterRegistry and MicrometerCollector classes for collecting data snapshots; and a new RowState inner class, defined in the MultiGauge class, that eliminates the need to remove and re-register an instance of the existing Row inner class. More details on this release, including deprecations, may be found in the release notes.
Similarly, the GA release of Micrometer Tracing 1.8.0 delivers bug fixes, documentation improvements, dependency upgrades and new features such as: a simplification of baggage handles and lookups by directly storing the name of the handle and its metadata by eliminating use of the CompositeBaggage and Java AtomicReference classes; and a refactor of the BaggageTextMapPropagator class for improved baggage propagation. Further details on this release, including deprecations, may be found in the release notes.
