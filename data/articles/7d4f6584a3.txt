An 11-year-old Linux kernel vulnerability, dubbed NoisyTCP, affects almost all Linux distributions and lets attackers crash systems running Nginx, Apache, and SSH servers with default configurations.
According to Hyunwoo Kim, the security researcher who discovered it, this pre-authenticated remote corruption flaw (tracked as CVE-2026-99288) stems from a NULL pointer dereference weakness in the Linux kernel's TCP networking subsystem.
Unauthenticated attackers can trigger it remotely via maliciously crafted TCP packets that exploit the timing between SYN cookie handling and socket hashing to crash the kernel and operating system on targeted servers.
However, while CVE-2026-99288 exploits cause a kernel panic and take down the host, they don't allow threat actors to alter data or gain arbitrary code execution.
Kim added that although attackers can exploit this vulnerability against any Linux system that receives TCP packets directly and runs Nginx, Apache, or an SSH server, "the race window is narrow, so triggering it against a quiet bare-metal server can take a long time."
"Due to a race condition during lockless socket lookups, recycled socket memory can be accessed before it is properly initialized and hashed. A remote attacker could exploit this issue by generating network traffic that drives socket reuse, triggering a NULL pointer dereference and kernel crash that results in a Denial of Service (DoS)," the Red Hat security team explained.
"To trigger this vulnerability, a stale ehash lookup and the freeing and reallocation of an existing request socket must proceed concurrently in different RX contexts. Packet processing has to be spread out by using the difference in receive hash between IPv4 fragments and regular TCP packets, so it can be triggered against servers that have two or more RX queues, or where RPS distributes packets across multiple CPUs," the researcher said.
While a CVE-2026-99288 patch is already available and a fix was already merged into the mainline Linux kernel two weeks ago, the researcher advised those who can't apply it or upgrade immediately to disable SYN cookies (which will unfortunately lower protection against SYN flood attacks) and serialize to a single RX queue to block the race required for successful exploitation.
In May, Kim also disclosed Dirty Frag, a Linux local privilege escalation flaw that chains RxRPC (CVE-2026-43500) and xfrm-ESP (CVE-2026-43284) page-cache write flaws to gain root access on major distributions, including Ubuntu, Red Hat Enterprise Linux, CentOS Stream, and Fedora.
More recently, in July, he also disclosed Januscape, a 16-year-old Linux kernel vulnerability that enables attackers to escape a virtual machine and run arbitrary code on the host.
