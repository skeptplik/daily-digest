ASUS released Control Center Express v1.7.29 to fix three critical vulnerabilities that could let remote attackers gain administrative control of the management console and the devices it manages.
Of the three, one is a maximum-severity vulnerability (CVSS score: 10.0) tracked under CVE-2026-114202, arising from a hard-coded cryptographic key used in the product.
The flaw lets an unauthenticated remote attacker forge an authentication token and gain administrator privileges, without requiring any privileges or user interaction.
The second flaw is CVE-2026-114204, also a hard-coded key problem, which lets a remote attacker with low privileges forge a session token for a recently logged-in account.
The third is CVE-2026-114205, an authorization flaw that lets a low-privileged user create an administrator account.
ASUS Control Center Express is a central dashboard that IT administrators use to monitor and remotely manage fleets of PCs.
ASUS markets it to businesses and IT service providers and lists support for more than 200 of its business, workstation, and Corporate Stable Model motherboards.
While all three vulnerabilities are rated critical, CVE-2026-114204 has a recent-session prerequisite, and CVE-2026-114205 requires a low-privileged account, whereas CVE-2026-114202 enables remote administrative access with no prerequisites.
ASUS’s security bulletin says versions earlier than v1.7.29 are affected. However, the CVE records only list affected versions through v1.7.27, leaving the status of v1.7.28 unclear.
Impacted users are advised to install v1.7.29, then update the agents on managed devices through Select Function → Client Agent Updater, and verify their versions.
Also yesterday, ASUS released security updates for Control Center Enterprise, its centralized IT management platform, and Armoury Crate, a hardware configuration utility.
Specifically, ASUS patched CVE-2026-126574, a critical authorization flaw that lets a remote user with the low-privileged Viewer role change an administrator’s password and take over the account.
The flaw affects Control Center Datacenter 4.0.0.2 and earlier and Control Center Enterprise 3.1.0.8 and earlier.
The Armoury Crate update addressed CVE-2026-112115, a high-severity privilege escalation flaw.
The flaw affects all versions up to and including 6.7.2 and could allow a low-privileged local user to trick an elevated process into loading a malicious library.
