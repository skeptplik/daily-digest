Hundreds of websites using the Optimizely website personalization platform served unsuspecting visitors a potent malware cocktail that targeted cryptocurrency wallets, stole payment card data, cookies, and screenshots, and delivered exploit kits for infecting iPhones and iPads, researchers said Tuesday.
ReportURI said it identified 178 websites—including CNN, Zoom, the BBC, and Salesforce—that were affected. JavaScript digitally signed by Optimizely and then loaded into customer pages had been modified to include malicious components that attempted to infect visitor devices with multiple payloads. When wares were installed successfully, they swapped user cryptocurrency wallet addresses for the attackers. Other components skimmed payment cards, stole cookies and screenshots, and, on iPhones and iPads, delivered iOS exploit kits known as Coruna and DarkSword.
Optimizely infrastructure delivers multipurpose malware
Optimizely serves JavaScript “snippets” that include both company code and code that is provided by each customer. The JavaScript, which can be served directly from Optimizely or from a customer endpoint, runs on every page the customer serves. Somehow, the attackers wrote their own code into a portion of each affected customer’s JavaScript and then delivered it from cdn.optimizely.com. A valid certificate for that domain signed the JavaScript.
ReportURI researcher Scott Helme said the delivery mechanism wasn’t a CDN cache poisoning attack, which uses HTTP to cause a CDN to cache harmful responses. Instead, the attack relied on Optimizely’s legitimate infrastructure, including its domains, to serve the tainted code. Optimizely’s own customer JavaScript for the www.optimizely.com and login.optimizely.com URLs were also affected.
“We don’t know how the attacker got write access to so many unrelated customer projects: a compromised Optimizely system, a compromised credential with cross-customer access, or something else,” ReportURI Helme wrote. “That’s for Optimizely to explain.”
Optimizely representatives didn’t respond to questions sent by email.
