Vim Classic 8.3.1 released
Version 8.3.1 of Vim Classic—a long-term support fork of Vim maintained without LLM assistance—has been released.
This release includes applicable Vim patches up to Vim 8.2.3237, including
numerous bug fixes, minor features, and compatibility improvements for Vim
plugins. This release also removes Python 2 support from Vim Classic.
The full list of changes in this release is available on sourcehut.
