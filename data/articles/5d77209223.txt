Ladybird, an independent web browser with a built-from-scratch engine, is finally available for testing. On Monday, Ladybird developer Andreas Kling announced that the browser is launching in alpha on macOS and Linux following more than four years of development.
Ladybird, the first new browser engine in years, is now available to test
Looking for a web browser without Google Chrome underneath? You can try this independent web browser now on macOS and Linux.
The release makes Ladybird the first browser in years to arrive with an entirely new engine. We’ve seen many engines emerge over time, but the most popular browsers use just three today: Gecko, Blink, and WebKit. While Gecko, now used in Mozilla Firefox, first appeared in Netscape 6 in 2000, Apple’s WebKit arrived in Safari in 2003 as a fork of KDE’s KHTML. A decade later, the Google-backed Chromium project forked WebKit to create Blink, which now powers Google Chrome, Microsoft Edge, Opera, and more.
Ladybird is backed by a nonprofit organization with the goal of creating “an independent, fast and secure browser that respects user privacy and fosters an open web,” according to its website. Though Ladybird development initially began as part of a C++ project, its developers eventually began porting the code to Rust using AI.
In his post announcing the alpha, Kling notes that the browser built around the Ladybird engine “is modest but functional,” adding that “some websites won’t work” during the alpha. A Windows version of Ladybird will arrive during a “later stage” of the project.
