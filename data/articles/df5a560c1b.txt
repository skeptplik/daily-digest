The Drupal Security Team has patched a critical remote code execution vulnerability that can let attackers take over vulnerable sites.
This content management system (CMS) is commonly used by large organizations that manage multi-site installations and massive data structures, including government entities, educational organizations, major research universities, and high-profile enterprise and media organizations.
The security flaw (tracked as CVE-2026-132165) was discovered by Anthropic's OSS Scanner, and anonymous users can exploit it to reinstall the Drupal CMS.
"Drupal core ships with an install.php file for installing Drupal core. Under specific conditions, an attacker can use the installer to attempt to reinstall Drupal. This can lead to a site takeover or remote code execution," the Drupal Security Team warned in a Wednesday advisory. "Some exploit paths are mitigated if the web server cannot write to or change permissions on settings.php."
Admins whose websites use the paid Drupal Steward Web Application Firewall (WAF) service are already protected from known attack vectors, but should still upgrade to Drupal 10.6.22, 11.3.22, or 11.4.13 in case other attack vectors are discovered.
Those who can't immediately upgrade should secure the Drupal installer by blocking access to /core/install.php in the web server configuration or the .htaccess file in the web root.
On Wednesday, Drupal also addressed a moderately critical gadget chain vulnerability (CVE-2026-132166) that attackers with admin privileges can exploit to gain remote code execution on a targeted site if the application deserializes untrusted data due to another security flaw.
"The Drupal Security Team urges you to reserve time for core updates at that time because exploits might be developed within hours or days," the security team said in a Monday advance warning. "The vulnerabilities are currently rated as critical and at least one can be exploited by anonymous users."
In May, Drupal also confirmed that attackers were actively exploiting an SQL injection vulnerability (CVE-2026-9082) in the database abstraction API that could let them escalate privileges, access sensitive information, or achieve remote code execution on unpatched servers.
More recently, Drupal warned that a critical access bypass vulnerability (CVE-2026-118539) in the Commerce Core module is being abused in attacks.
The US Cybersecurity and Infrastructure Security Agency (CISA) has flagged 5 Drupal vulnerabilities as exploited in the wild since November 2021, two of which have also been abused in ransomware attacks.
