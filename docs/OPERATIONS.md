# Эксплуатация

## Облачная задача Claude
- Где: https://claude.ai/code/routines («scheduled tasks» в новой терминологии). Название: «Утренний дайджест».
- ID: `trig_017E2QkParxE5gozcVmQzo2E`.
- Расписание: каждый день 06:12 по Europe/Warsaw (`CRON_TZ=Europe/Warsaw 12 6 * * *`; минута 12 выбрана сознательно, чтобы не попадать на круглые часы).
- Модель: `claude-sonnet-5-5` (Sonnet 5.5). Не оставлять «Default»: на Pro по умолчанию Opus 5.5, он быстро съедает лимит. Fable на Pro требует платных кредитов.
- Режим подтверждений: «Авто» (действия выполняются без запросов). Владелец это подтвердил; в данных задачи `permission_mode: auto`. Это нужно, потому что запуск идёт без человека.
- Репозиторий: `skeptplik/daily-digest`, GitHub подключён в claude.ai (коннектор/Claude GitHub App с правом записи). Тест: пуш в ветку `claude/...` из сессии проходил; из самой задачи пуш в `main` проходил (коммиты `580b68e`, `a98eedf`).
- Промпт хранится ВНУТРИ задачи, не читается из репозитория. `routine_prompt.md` в репозитории — копия-источник. После правки файла обновите промпт задачи (UI: открыть задачу → редактировать промпт; либо из сессии Claude через инструмент обновления задач).
- Кнопка «Запустить сейчас» (Run now): один тестовый прогон. Лимит 30 запусков в час на задачу, но каждый запуск тратит лимит подписки Pro, так что не жмите подряд. Нормальный результат: через несколько минут в `main` появляется коммит «Дайджест за ДАТА», затем автоматически идёт `publish.yml` и приходит сообщение в Telegram.
- Что проверить после запуска: итоговый ответ задачи (сколько новостей, сколько важных, `feeds_ok/feeds_failed`), коммит в `main`, зелёный `publish.yml`.
- Не используйте WebSearch/WebFetch в промпте: во время запуска без человека запросы доступа к сайтам блокируют работу (подтверждено тестом B).

## GitHub
- Секреты: Settings → Secrets and variables → Actions → `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (значения нигде не хранятся в проекте; менять карандашом).
- Pages: Settings → Pages → Source: GitHub Actions.
- Ручные запуски: Actions → нужный workflow → Run workflow: `Collect news` (обновить заголовки), `Publish digest` (пересобрать и разослать текущий `digest.json`, придёт сообщение в Telegram), `Check digest` (проверка).
- Ветка `claude/push-test` — мусор от теста, можно удалить.

## Windows
- Скачивание дайджеста на ПК (задача DailyDigest, local/, папка C:\Digests) убрано 4 ноября 2026 по решению владельца; дайджест читается только на телефоне.

## Telegram
- Бот владельца (токен у владельца в BotFather), `TELEGRAM_CHAT_ID` — личный числовой ID.
- Одно сообщение: заголовок, «🔥 Главное» (до 7 пунктов с иконками тем), ссылка вида `https://skeptplik.github.io/daily-digest/?d=ДАТА-ЧЧММ`. Демо помечается «🧪 ДЕМО».
- Сообщение о сбое присылает `check.yml`: «⚠️ Дайджест на сегодня не собран» + причина + что сделать.

## Типовые поломки
| Симптом | Причина / действие |
|---|---|
| Нет сообщения утром, пришло «не собран» | Открыть Actions (Collect news зелёный? `candidates.json` свежий?), затем claude.ai/code/routines: итог последнего запуска; затем «Run now» |
| Actions → Publish digest красный | Открыть красный шаг. Pages: Settings → Pages → Source: GitHub Actions. notify 400/404: проверить секреты и что боту нажато Start |
| В странице вчерашние новости | Кэш: открыть ссылку из нового сообщения (с `?d=`) или обновить; проверить дату в шапке |
| Много карточек без фото | Лог шага Build page: строки «Фото: …» и «Без фото (источники…)»; проверить `image` в `candidates.json` |
| Лента не грузится | `feeds_failed` в `candidates.json`; заменить URL в `data/feeds.json` |
| Задача Claude пишет «сырьё не обновилось» | `candidates.json` старше 30 часов: перезапустить Collect news |

## Стоимость
Только подписка Claude Pro (лимит на запуск задачи). GitHub Actions/Pages бесплатны для публичного репозитория. Реальный расход лимита ещё не измерен (claude.ai → Settings → Usage).
