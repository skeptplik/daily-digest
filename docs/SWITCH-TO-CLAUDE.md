# Runbook: вернуть роль редактора дайджеста облачной задаче Claude

Как пользоваться: откройте Claude (Claude Code в папке проекта или сессию в приложении) и напишите: «Открой docs/SWITCH-TO-CLAUDE.md и выполни по шагам, останавливайся там, где нужно моё действие».

Одновременно должен работать ОДИН редактор. Сначала остановите Codex, потом включайте Claude.

## Для агента (Claude): порядок действий

### Шаг 1. Состояние
`git fetch origin main && git checkout main && git pull`. Прочитайте `AGENTS.md`, `docs/STATUS.md`, `docs/OPERATIONS.md`, `routine_prompt.md`, `data/engine.json`. Если `engine` уже `claude`, а облачная задача включена, сообщите и остановитесь.

### Шаг 2. Остановить Codex (действие владельца)
Попросите: «Откройте в Codex автоматизацию «Утренний дайджест» и выключите/удалите её расписание. Напишите, когда сделано». Дождитесь подтверждения. Не продолжайте, пока не подтвердили.

### Шаг 3. Включить или создать облачную задачу Claude
Сначала определите, что вам доступно:
- Если в вашей сессии есть инструменты управления запланированными задачами (создание/обновление scheduled task): работайте через них. Сначала посмотрите список задач и найдите «Утренний дайджест» (прежний ID `trig_017E2QkParxE5gozcVmQzo2E`). Если задача есть: включите её (enabled) и сверьте расписание, модель и промпт (ниже). Если нет: создайте.
- Если таких инструментов нет (обычный Claude Code в VS Code): дайте владельцу точные клики и ждите подтверждений:
  1. claude.ai/code/routines → найти «Утренний дайджест». Если есть: включить расписание. Если нет: «New routine».
  2. Параметры (как в `docs/OPERATIONS.md`): модель **Sonnet 5.5** выбрать явно (не Default), репозиторий `skeptplik/daily-digest`, режим подтверждений **Авто** (действия без запросов), включить **Allow unrestricted branch pushes**, расписание ежедневно **06:12** часовой пояс **Europe/Warsaw**.
  3. Промпт задачи: короткий запуск вида «Репозиторий skeptplik/daily-digest (ветка main). Если локальной копии нет, клонируй: git clone --depth 1 https://github.com/skeptplik/daily-digest /home/claude/daily-digest. Прочитай routine_prompt.md в корне репозитория и выполни его целиком». Полный промпт задача читает из файла при каждом запуске (AGENTS.md, правило 6); копировать его в claude.ai не нужно. В `routine_prompt.md` не должно быть WebSearch/WebFetch: задача работает без человека.

Если вы создавали задачу заново, ID изменится: обновите его в `data/engine.json` и `docs/OPERATIONS.md`.

### Шаг 4. Зафиксировать
В `data/engine.json`: `"engine": "claude"`, `"since"` на сегодняшнюю дату, актуальный `claude_routine_id`. Добавьте строку в `docs/STATUS.md`. Закоммитьте («Движок дайджеста: Claude») и запушьте.

### Шаг 5. Тестовый запуск
Попросите владельца нажать «Запустить сейчас» (Run now) один раз. Проверьте: коммит «Дайджест за ДАТА» в `main`, `publish.yml` зелёный, сообщение в Telegram. Помните: тестовый запуск расходует лимит подписки.
