# Решения, предпочтения владельца, отвергнутые варианты

## Профиль владельца (важно для общения и дизайна)
- Говорит по-русски, живёт в Польше (часовой пояс Europe/Warsaw; до 29 марта 2027 UTC+1, затем UTC+2). Читает дайджест в основном на телефоне Poco F6 Pro (ширина ~393 px), также Windows 10.
- Подписка Claude Pro. За токены API платить НЕ готов. Хочет экономить лимит подписки.
- Время важно: дайджест нужен, чтобы быстро узнать главное за вчера. Места на экране мало.
- Нейтральность и достоверность, особенно в политике; источники независимые и проверенные; пересказы по-русски.
- Читатель не знает английский: русские версии статей предпочтительнее (BBC Русская служба, DW, France 24).

## Принятые решения
1. **Вариант 1 из трёх**: облачная задача по расписанию в самом Claude (а не VPS, не локальный ПК, не API). Работает при выключенном ПК, ничего не зависит от Claude Code на ПК. Токен Claude нигде не передаётся.
2. **Доставка**: GitHub Pages (ссылка) + Telegram. Изначально было две вещи (ссылка + файл); по просьбе владельца в Telegram теперь одно сообщение только со ссылкой. Файл для чтения остаётся на ПК через задачу Windows.
3. **Дизайн «Сторис»** (как истории Instagram) из пяти вариантов. Требования владельца: кнопка «Смотреть только важное» (не «все подряд»), плитки тем с превью новостей и настоящими фото из статей, индикаторы важности, ленты/плитки с листанием.
4. **Язык: только русский.** Переводы RU/EN/DE были реализованы, но отключены владельцем ради лимита (шаблон поддерживает их, если появятся `i18n`).
5. **Модель: Sonnet 5.5, Effort Medium**. Opus лишний и дорогой, Haiku слабее на многошаговых задачах. Выбирать явно.
6. **Источники**: `data/sources.json` (доверенные издания по категориям + первоисточники). Политика: минимум два независимых издания либо пометка и importance ≤2. Государственная пропаганда, блоги, соцсети, SEO, мнения исключены.
7. **Интернет вынесен из облачной задачи на GitHub Actions** (RSS). Причина: тесты A и B показали, что поиск в задаче без человека ненадёжен (прокси, старые результаты, запросы подтверждений).
8. **Приоритет по важности**: темы и новости сортируются по importance; «Любопытное» вынесено в отдельную тему, чтобы основные оставались серьёзными, но курьёзы (владельцу интересны) не терялись.
9. **Озвучка** в маленькой кнопке рядом с переключателем темы (чтобы не занимать место).
10. **Сообщение о сбое** обязательно (владелец: «100% надо»).

## Рассмотрено и не сделано (пока)
- Экран «За 60 секунд» — владелец: не нужен.
- Приложение (PWA) и офлайн: польза небольшая; альтернатива без кода — Chrome → «Добавить на главный экран». Обсуждалось, решение отложено.
- Разделение кнопки «важное» на два уровня («супер важное» и «важное») — владелец решил оставить одну кнопку.
- Платный API / Claude API — отвергнуто (расходы).
- Фото через поиск Claude — отвергнуто (токены). Фото берутся из RSS/og:image на Actions.

## Вопрос о смене ИИ-движка (обсуждался)
Если подписка Claude закончится: сбор заголовков, сборка, публикация, Telegram и проверка сбоя продолжат работать (GitHub), остановится только отбор и пересказ. Варианты: (1) вручную прогонять `routine_prompt.md` + `candidates.json` через ChatGPT или другой ИИ и вставлять результат в `data/digest.json`; (2) автоматический шаг на Actions с другой моделью по ключу (бесплатные лимиты у некоторых сервисов; не проверено); (3) запасной режим без ИИ — публиковать заголовки автоматически. См. `docs/ROADMAP.md`.

## Известные слабые места
- Пересказы короткие: Claude видит только заголовок и первую строку из RSS.
- Метки «подтверждено» строятся по совпадению доменов, а не по смыслу: две ссылки на одно издание не считаются независимыми, но близкие по теме статьи двух изданий считает независимыми сам Claude.
- Курьёзы и важность оценивает модель; в мелочах она ошибается.
- Если задачу Claude остановить (нет подписки, лимит), дайджест не обновится: сработает только `check.yml` с сообщением о сбое. Запасного режима без ИИ пока нет (см. `docs/ROADMAP.md`).

## Замечания владельца по результату C и принятые решения
- Два сообщения в Telegram → одно текстовое со ссылкой (файл в Telegram не шлётся).
- Кэш Telegram открывал вчерашнюю страницу → к ссылке добавляется `?d=ДАТА-ЧЧММ`, в странице мета no-cache.
- Заглушки вместо фото → картинки из RSS (`media:content`, `media:thumbnail`, `enclosure`, `<img>`), затем og:image; к запросам добавлен Referer. Строка лога «Фото: из RSS N, из og:image M, не найдено K» (шаг Build page).
- Курьёзы в основных темах → тема `curious` («Любопытное»): всегда последняя, важность 1.
- Порядок тем и новостей по важности; кнопка «🔥 Смотреть только важное» (до 10, обычно 3–7 с importance 3) всегда первая; кнопка 🔊 читает заголовок дня и важные новости.

## Читалка, источники, облачная задача (сессия 1–2 ноября 2026)
- **Зачем читалка.** Сайты изданий (BBC, DW и др.) у владельца бывают недоступны (блокировки, в том числе при русском VPN), а оригиналы английские. Поэтому «Читать» открывает русский рассказ на нашей странице (поле `body` в `digest.json`), кнопки на оригинал нет. Если у новости нет `body`, кнопки «Читать» нет вообще. Платные издания (nytimes, wsj, ft, economist, bloomberg, washingtonpost) без полного текста: только заголовок и описание как подтверждение события; обход пейволлов не делаем.
- **Проба доступности из Actions (1 ноября):** тексты отдают BBC, DW (en/ru), Guardian, NPR, Al Jazeera, The Hindu, SCMP, Japan Times; NYT и Times of Israel дают 403. `collect.py`: 132 текста из 146, около 530 КБ в день (`data/articles/`, вчерашние удаляются).
- **Комментарии.** Reddit даёт 403 на анонимные запросы и с Actions, и с домашнего ПК (Польша); остаётся официальный API с приложением типа script (`REDDIT_CLIENT_ID`, `REDDIT_CLIENT_SECRET`; имя пользователя и пароль не нужны, но одобрение новых приложений у Reddit не гарантировано). Hacker News (Algolia, поиск по точной ссылке) нашёл обсуждение лишь у 5 из 82 ссылок, комментариев почти нет; Bluesky 403, Lobsters отдаёт HTML, Mastodon без входа пусто. Владельцу нужны комментарии именно по этой новости, а не «по теме».
- **Мусор в текстах.** В хвостах статей попадались «You must confirm your public display name…», «Published - …», призывы подписаться в соцсетях; убираются регулярным фильтром `strip_junk` в `collect.py`. Подписи авторов остаются, промпт велит их пропускать.
- **Группы событий.** `group_rows` в `collect.py` (общие редкие слова, порог 0.25 и вес не меньше 3.5): на реальных заголовках 5 групп из 5 верных; мягче порога склеивались чужие новости. Русские и английские заголовки не сводятся, группа только подсказка для Claude.
- **Лимиты и вид дайджеста (решение владельца).** До 4 основных новостей на тему (обычно 2–3, четыре при горячих), до 5 мелких с `minor: true`. Основные идут первыми. Главная новость темы крупная карточка, остальные основные строками (у 🔥 с кратким описанием), мелкие горизонтальной лентой квадратов; фото не лежат под текстом. Текстовый список «Также интересно» владельцу не понравился.
- **Перевод.** Один субагент Haiku на все статьи сразу: запуск субагента стоит около 28,5 тыс. токенов даже на одной фразе, поэтому «по одному на статью» дороже. Проба на трёх статьях: числа, имена и «кто что заявил» совпали; мелкие смысловые огрехи («фаворит крайне правых» вместо «лидирующая крайне правая», «township» без перевода, пропуск слова «год»); поэтому Sonnet выборочно сверяет 2–3 рассказа. Цель по расходу: не больше 5% дневного лимита Pro (не измерено).
- **API облачных задач (`RemoteTrigger`).** Промпт лежит в `job_config.ccr.events[1].data.message.content`; `events[0]` это `set_permission_mode` auto. Обновление `job_config` **заменяет его целиком**: без `session_context` пропадают модель, репозиторий, инструменты (проверено на временной задаче, `session_request` ведёт себя так же). Обновлять нужно с полным `environment_id`, `events` и `session_context` (модель, `sources`, `allowed_tools`, `disallowed_tools`). Служебный системный промпт приложения (72 КБ, `custom_system_prompt`) и `mcp_config` с `remote-devices` намеренно не переданы; прежняя полная копия лежит в папке `.claude/backups` в профиле пользователя. Задачи удалять через API нельзя, только в `claude.ai/code/routines`.
- **Ловушки окружения.** (1) Безголовый Chrome для снимков: если у владельца запущен обычный Chrome, запуск из Bash молча не пишет файл; рабочий способ: PowerShell `Start-Process chrome.exe` с `--headless=new`, отдельным `--user-data-dir`, `--window-size=500,H`, `--screenshot=<путь>` и страницей в `iframe` шириной 393 px (окно меньше 500 px безголовый Chrome не делает). (2) Тестовый воркфлоу на ветке, сохраняющий результат коммитом, должен делать `git push origin HEAD:<ветка>` без `git pull --rebase`: после `collect.py` в рабочей папке изменённые данные, и `pull --rebase` падает. (3) Пуш в `main` без изменения `data/digest.json` рассылку не запускает (`publish.yml` срабатывает только по этому файлу). (4) Windows-пути с `\U` в обычных строках Python внутри heredoc ломают скрипт: писать текст через `cat <<'EOF'` или raw-строки.
