# Планы и идеи

## Рекомендуемое ближайшее
1. Проверить первый плановый запуск 2 ноября (см. чек-лист в `docs/STATUS.md`).
2. Посмотреть строку «Фото: …» в логе Build page и починить фото, если не хватает (заменить URL лент, добавить `og:image` в запасной путь, обработать hotlink-защиту).
3. Запустить `Check digest` вручную и убедиться, что проверка молчит при успехе.
4. Измерить расход лимита Pro после 3–5 суток; при необходимости сократить число заголовков на тему (`DEFAULT_PER_TOPIC` в `collect.py`) или перейти на более лёгкую схему.

## Запасной режим без ИИ (страховка)
Если к 07:00 дайджест не обновлён, отдельный шаг Actions собирает `digest.json` из `candidates.json` без пересказов: по 1–2 новости на тему, заголовки на языке оригинала (или с кнопкой перевода в Chrome), без «важного». Помечать страницу «автоматический режим, без ИИ». Хорошо сочетается с `check.yml`.

## Смена движка (ChatGPT, Gemini и др.)
- Ручной: файл `docs/handoff-prompt.md` (создать): промпт + инструкция вставить `candidates.json`, получить `digest.json`, закоммитить.
- Автоматический: `scripts/summarize.py` с провайдером на выбор (`PROVIDER=claude|openai|gemini`) и секретом ключа; запуск в Actions после collect. Проверить актуальные бесплатные лимиты провайдера до внедрения.

## Идеи из обсуждения
- Архив прошлых дней со списком и поиском (хранить `archive/DATE.html` на Pages).
- «Прочитаю позже» (localStorage) и пометка «продолжение вчерашней истории».
- Воскресная сводка недели.
- Прямая ссылка `?only=hot`, открывающая сразу «только важное»; inline-кнопка в Telegram вместо ссылки в тексте.
- PWA: иконка на экране и офлайн-доступ к последнему дайджесту.
- Больше изданий в `feeds.json` по интересам (игры, дизайн), русскоязычные ленты.
- Обновить версии действий (`actions/*@v4/v5`), когда Node 20 перестанет поддерживаться.
