# Дополнения для Claude Code

- Читайте `docs/STATUS.md` перед началом работы: там текущее состояние, результаты тестов и открытые вопросы.
- Облачная задача (routine) «Утренний дайджест» редактируется в claude.ai (claude.ai/code/routines) или инструментом обновления задач из сессии Claude с доступом к ним. Из VS Code обычно доступна только правка `routine_prompt.md`.
- Комиты в репозиторий владельца делайте короткими, по-русски, без лишних файлов (`out/`, `site/`, `__pycache__/` в `.gitignore`).
- Текущий статус: `docs/STATUS.md`. Сессии: `/pickup` (начать), `/handoff` (закончить).

## Сложное (порядок «Осторожно»: копия, проба, план и «да»; Opus — только после двух неудач и с подтверждения)
- Пуш в `main` с изменённым `data/digest.json` запускает публикацию и Telegram-рассылку; воркфлоу, `local/*.ps1`, секреты, `routine_prompt.md` (копия в облачной задаче) — по плану и с «да».
- Чужие системы: GitHub Actions/Pages, Telegram Bot API, облачные задачи Claude; сеть из песочницы недоступна, сетевые части подтверждаются только логом запуска.
- Подсказки для роутинга: `.claude/skills/pickup/routing.md`.
