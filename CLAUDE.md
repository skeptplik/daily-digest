# Дополнения для Claude Code

- Читайте `docs/STATUS.md` перед началом работы: там текущее состояние, результаты тестов и открытые вопросы.
- Облачная задача (routine) «Утренний дайджест» редактируется в claude.ai (claude.ai/code/routines) или инструментом обновления задач из сессии Claude с доступом к ним. Из VS Code обычно доступна только правка `routine_prompt.md`.
- Комиты в репозиторий владельца делайте короткими, по-русски, без лишних файлов (`out/`, `site/`, `__pycache__/` в `.gitignore`).
- Смена редактора: если владелец просит «переключись на Codex/Claude» или «будь главным», действуйте по разделу «Смена редактора дайджеста» в `AGENTS.md` и runbook `docs/SWITCH-TO-CLAUDE.md` / `docs/SWITCH-TO-CODEX.md`.
